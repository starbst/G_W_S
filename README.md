# 高达战争模拟器

SillyTavern 的 3D 高达战斗扩展，可搭配不同角色卡和聊天预设使用。AI 生成方案，玩家确认后开始本地战斗，结束后可将战报写回聊天。

## 安装

1. 安装并启用 **酒馆助手**和**提示词模板**。
2. 在酒馆“扩展程序 → 安装扩展程序”中输入本仓库的 Git URL，安装后刷新页面。
3. 从左下角魔法棒里的“高达战斗模拟器”或悬浮按钮打开界面，展开“导入世界书资料包”，选择 SEED、高达00或两者，点击导入。

助手脚本和正则会自动安装。若没有正常添加，可手动导入仓库内的 [助手脚本](tavern-helper.json)和[正则](exports/regex/gws-chat.json)。

## 使用

1. **准备战斗**：勾选“随 AI 回复提出战斗方案”，正常进行 RP。回复出现“进入战斗”按钮后，点击载入方案。也可在模拟器中点击“从对话提取预设”，或选择内置预设。
2. **开始战斗**：检查并调整机体、驾驶员、编组和任务，点击“确认方案 · 开始本地战斗”。战斗期间不调用模型。
3. **写回聊天**：战斗结束后展开“本轮战报 / 写回聊天”，按需编辑战报，点击“本轮注入战报”，再回到聊天框正常发送自己的内容。战报不会覆盖输入框，也可随时清空。

内置预设默认随机运行；想使用已测试的参考值，可在导入前勾选“导入种子”。参考种子不代表全部剧情细节都能还原。

修改或删除世界书后，点击“刷新世界书”更新列表和当前内容。

地图操作：**左键旋转、右键或 WASD 平移、滚轮缩放**；地图获得焦点时按**空格暂停**。

战斗录像自动保存在当前浏览器，可在录像库播放或导出。换设备前请先导出备份。

AI 没有给出方案时，可手动生成；额外模型调用会先提示确认。想调整战局，可填写“玩家要求”后点“重新生成预设”：AI 会结合当前聊天，调整你指定的部分。

移动端可通过“作战配置 / 战术地图”切换页面，地图支持单指旋转、双指缩放和平移。

内置SEED与高达00资料包均可独立使用，也可一起关联。可关联多本参数世界书，用 ↑ / ↓ 调整优先级；同名或同ID资料对外优先采用上方世界书，词条内部先引用本书，再从其他关联书补充。整备室每次只编辑所选一本，保存后刷新全部关联资料。可在配置页勾选或取消“显示悬浮按钮”，隐藏后仍能从魔法棒进入。
